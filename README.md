# music-freedom

Переносит избранные треки между Яндекс Музыкой и Spotify и поддерживает их одинаковыми. Работает на вашем компьютере: токены и библиотека никуда не отправляются.

- Перенос в любую сторону или в обе сразу. То, что уже есть в избранном, не дублируется.
- Перед записью видно, что добавится, что уже есть и что не нашлось. Спорные совпадения можно проверить по одному.
- Удаления не переносятся. Программа ничего не удаляет из библиотек, кроме отмены собственного переноса.
- Последний перенос можно отменить: добавленные треки уберутся.

Сейчас переносятся только избранные треки. Плейлисты и альбомы будут позже.

## Запуск

1. Скачайте архив для своей системы со страницы Releases и распакуйте его.
2. Запустите файл `music-freedom`. Откроется вкладка браузера с программой и окно консоли. Не закрывайте консоль, пока пользуетесь программой: её закрытие выключает программу.

Программа не подписана, поэтому система предупредит о неизвестном разработчике при первом запуске:

- **Windows:** в окне «Windows защитила ваш компьютер» нажмите «Подробнее», затем «Выполнить в любом случае».
- **macOS:** откройте «Системные настройки → Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и запустите файл ещё раз.

## Подключение сервисов

**Яндекс Музыка.** Нажмите «Получить код», откройте ya.ru/device и введите показанный код. Пароль программа не видит.

**Spotify.** Spotify пускает сторонние программы только через ваше собственное приложение разработчика, и его владельцу нужен Spotify Premium. Программа проведёт по шагам:

1. Откройте [Spotify Dashboard](https://developer.spotify.com/dashboard) и создайте приложение (Create app).
2. В Redirect URIs добавьте ровно `http://127.0.0.1:47813/callback`: именно http и с портом.
3. В APIs used отметьте Web API и сохраните.
4. Скопируйте Client ID в программу и нажмите «Войти через Spotify».

**VPN.** Из России Spotify работает только через VPN. Яндекс Музыка с VPN тоже работает: программа обращается к ней по IPv4, где большинство VPN не ломают соединение. Если сервис недоступен, на его деке появится сообщение и кнопка «Повторить».

## Как ищутся треки

Сначала по ISRC (у Яндекса его нет), затем по исполнителю и названию с учётом транслита («Кино» и «Kino»), пометок версии (Remastered, feat.) и длительности. Уверенные совпадения добавляются сами, сомнительные ждут вашего решения, а ненайденные можно выгрузить списком. Найденное запоминается, поэтому повторная синхронизация идёт быстро.

Данные программы лежат в `~/.music-freedom/`: `tokens.json` (входы, доступ только у владельца) и `data.sqlite` (найденные совпадения и история переносов).

## Разработка

Нужен [Bun](https://bun.sh).

```sh
bun install
bun run dev            # сервер с перезагрузкой на http://127.0.0.1:47813
MF_DEMO=1 bun run dev  # демо: выдуманные библиотеки, настоящие аккаунты не трогаются
bun test
bun run lint
bun run typecheck
bun run build          # исполняемые файлы и zip под Windows, macOS и Linux в dist/app/
bun run probe          # консольная проверка API на живых аккаунтах, только чтение
```

Сборка под все платформы делается с одной машины. Тексты интерфейса лежат в `src/web/i18n/ru.ts`; английский перевод повторит эту структуру. Новый сервис реализует интерфейс `MusicService` из `src/core/service.ts`.
