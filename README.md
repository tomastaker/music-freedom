# music-freedom

Локальное приложение для переноса и синхронизации музыкальной библиотеки между сервисами. Начинаем с избранных треков Яндекс Музыки и Spotify.

Статус: этап 0, проверка API на живых аккаунтах.

## Разработка

Нужен [Bun](https://bun.sh).

```sh
bun install
bun test
bun run probe          # проверка на живых аккаунтах, только чтение
bun run build:probe    # сборка проверки под Windows, macOS и Linux в dist/
```

Токены хранятся в `~/.music-freedom/tokens.json` с правами только для владельца.
