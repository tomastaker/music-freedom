# Design System: music-freedom

## Overview

**Creative North Star: "Двухкассетник"**

Перенос музыки показан как перезапись с деки на деку. Корпус из чёрного пластика, две алюминиевые деки с окнами ленты, по центру переключатель направления и одна красная круглая кнопка записи. Размер библиотеки читается по янтарным цифрам в чёрных окошках и по толщине намотки на катушках. Интерфейс спокойный и плотный: это инструмент для редкой, но ответственной задачи, а не витрина.

Мир держится на материалах: пластик (`body-plastic`, `surface`) для рабочих областей, алюминий для деки и главной клавиши, чёрное стекло окошек для всего, что считается. Декор ради декора не добавляется: каждая деталь корпуса несёт данные (счётчик, катушка, табличка «Дека А · воспроизведение»).

Интерфейс на английском и русском, язык выбирается по браузеру и переключателем EN/RU в верхней панели. По-русски обращаемся на «вы». Строки лежат в `src/web/i18n/en.ts` и `ru.ts` с одинаковой структурой; ошибки сервер отдаёт кодами, текст собирает словарь.

**Key Characteristics:**
- Тёмная тема, единственная (`color-scheme: dark`).
- Три материала: пластик, алюминий, чёрное окошко.
- Красный только у записи, янтарь только у цифр и положительных значений, кирпичный только для «не найдено» и ошибок.
- Движение осмысленное: цифры прокатываются, катушки крутятся только пока идёт работа.

## Colors

Палитра нейтральная и тёмная, с двумя сигнальными цветами и одним предупреждающим. Цвета сервисов существуют только как маленькие точки.

### Primary
- **Красная клавиша записи** (`rec-red`, hover `rec-red-hover`): круглая кнопка записи; в отключённом виде `#4a2622` с текстом `#a98a86`.
- **Янтарь счётчиков** (`amber`): цифры в чёрных окошках, положительные значения («добавится»), фокус-кольцо, выбранные карточки (рамка), прогресс, `::selection`. `amber-dim` зарезервирован токеном.

### Secondary
- **Кирпич** (`brick`): «не найдено», ошибки поля, иконка баннера ошибки. Фон баннера ошибки `#2c1a18`, текст `#f2c3bb`.
- **Алюминий** (`aluminium-top` → `aluminium-bottom`, вертикальный градиент): панели дек и главная клавиша области (`button-primary`). Текст на нём `aluminium-text`, вторичный `aluminium-dim`.

### Neutral
- **Чёрный пластик** (`body-plastic`): фон страницы.
- **Панель** (`surface`) и **поднятая панель** (`surface-raised`): рабочая область, карточки, вкладки, кнопки по умолчанию.
- **Линия** (`line`): все границы и разделители; внутри таблицы мягче, `#292b2f`.
- **Окошко** (`window-black`): фон счётчиков, окна ленты, полей ввода, сегментов направления, дорожки прогресса.
- **Текст** (`text`) и **приглушённый** (`text-dim`).
- **Цвета сервисов** (`service-yandex`, `service-spotify`): только точка 10px рядом с названием.

Тона счётчика: по умолчанию янтарь; `dim` `#8b9097` (нет данных или нейтрально), `brick` (не найдено), `off` `#3b3d42` (выключен).

### Named Rules
**The One Red Rule.** Красный (`rec-red`) принадлежит кнопке записи. Больше ничего на экране не красное.
**The Amber Is Digits Rule.** Янтарь означает цифру или положительное значение. Не используйте его для декоративных заливок, заголовков и кнопок.
**The Aluminium Key Rule.** Главное действие области: алюминиевая клавиша. Не красная и не янтарная.
**The Brick Means Missing Rule.** Кирпич только для «не найдено» и ошибок.

## Typography

**UI Font:** Golos Text (запасной system-ui, sans-serif)
**Digit Font:** Share Tech Mono (запасной ui-monospace, monospace)

Шрифты подключены пакетами `@fontsource/golos-text` и `@fontsource/share-tech-mono` в `src/web/main.tsx` и при сборке встраиваются в CSS, поэтому работают без интернета.

**Character:** гротеск для всего читаемого текста и моноширинный «приборный» шрифт для всего, что считается.

### Hierarchy
- **Deck name** (700, 22px, -0.015em; 16px на узком экране): название сервиса на деке.
- **Review track** (600, 26px, 1.2): трек в разборе спорных.
- **Section title** (600, 20px): заголовки подключения и хода работы; пустое состояние 22px.
- **Body** (400, 15px, 1.45): основной текст; вторичный 13-14px `text-dim`.
- **Plate** (600, 12px, 0.08em, верхний регистр): табличка деки «Дека А · воспроизведение», на узком экране скрыта.
- **Counter** (Share Tech Mono, 40px; small 28px; 26px/22px на узком экране; код устройства 44px с разрядкой 0.18em): цифры в окошках.
- **Inline digits** (Share Tech Mono, 13-15px): длительность, счётчик фильтра, дата истории, шаг процесса, поля ввода кода.

### Named Rules
**The Mono Is For Counting Rule.** Share Tech Mono только для чисел, кодов и дат. Слова набираются Golos Text (исключение: поле ввода кода).
**The Tabular Rule.** Счётчики используют `tabular-nums`, чтобы цифры не прыгали.

## Layout

Оболочка `.shell`: максимум 1360px по центру, горизонтальные поля 32px. Верхняя панель высотой 64px: бренд и вкладки «Перенос» / «История».

Консоль: сетка `минимум 1fr / 232px / 1fr` с промежутком 20px: дека А, транспорт, дека Б. Под ней четыре индикатора в ряд (промежуток 12px, отступ 20px), ниже рабочая область (отступ 20px, мин. высота 360px) с внутренним отступом 28px.

- **До 1080px:** консоль в одну колонку; индикаторы 2x2; подключение и разбор спорных в одну колонку, вертикальная граница заменяется горизонтальной.
- **До 640px:** поля оболочки 16px; деки в две колонки (промежуток 10px) с компактным отступом 14px, транспорт на всю ширину второй строкой; окно ленты, табличка, имя аккаунта и подпись счётчика скрыты; счётчики деки 26px, индикаторов 22px (индикаторы столбиком); поиск на всю ширину; таблица прокручивается по горизонтали (мин. ширина 640px); строки истории в одну колонку.

Ритм отступов: 8, 12, 20, 28. Таблица прокручивается внутри себя (макс. высота 560px) с липкой шапкой.

## Elevation & Depth

Гибрид: тональные слои для пластика и физические тени для деталей корпуса. Рабочие области плоские: граница `line`, без теней. Объём получают только деки, окошки и кнопка записи.

### Shadow Vocabulary
- **Дека** (`box-shadow: inset 0 1px 0 rgb(255 255 255 / 0.6), 0 10px 30px rgb(0 0 0 / 0.35)`): блик на кромке алюминия и тень на корпус.
- **Вдавленное окошко ленты** (`inset 0 3px 8px rgb(0 0 0 / 0.65)`).
- **Вдавленный счётчик** (`inset 0 2px 5px rgb(0 0 0 / 0.7)`).
- **Кнопка записи** (`0 0 0 5px var(--surface-2), 0 6px 16px rgb(0 0 0 / 0.45)`): кольцо-ободок и тень.
- **Точка сервиса** (`0 0 0 2px rgb(0 0 0 / 0.15)`).
- **Выбранный сегмент** (`inset 0 0 0 1px var(--line)`).

### Named Rules
**The Inset Means Display Rule.** Вдавленная тень (inset) только у окошек, где показывают данные. Остальное не вдавливается.

## Shapes

Два радиуса: `control` 6px (кнопки, поля, счётчики, вкладки, кандидаты) и `panel` 10px (деки, индикаторы, рабочая область). Сегменты направления: контейнер 8px, пункт 5px. Круг: кнопка записи (88px), точки сервисов, номера шагов, катушки. Окно ленты: капсула 46px при высоте 92px. Дорожка прогресса: 3px. Границы 1px `line`.

## Components

### Дека
Алюминиевая панель с градиентом. Сетка: имя сервиса с цветной точкой и аккаунтом слева, счётчик справа, ниже окно ленты, ниже ошибка (если есть), в подвале табличка и действия (`deck-link`: подчёркнутые кнопки `aluminium-dim`, при наведении `aluminium-text`).
- **Состояния** (`data-state`): подключена; отключена (окно ленты с прозрачностью 0.55); ошибка (текст `#8f2316`, 13px, 500).
- **Окно ленты:** чёрная капсула: катушка, лента 5px цвета `#6b4a2b`, катушка. Намотка (`reel-pack`) меняет радиус и толщину за 600ms по размеру библиотеки.
- **Катушки:** серые `#6c7078`; при `.is-running` янтарные и вращаются (1.6s linear, бесконечно). Вне работы стоят.

### Счётчик
Чёрное окошко с янтарными цифрами. Каждая цифра: колонка 0-9 за маской высотой 1em, прокатывается за 520ms `ease-out`. Размеры: обычный 40px, `counter-small` 28px. Тоны: `dim`, `brick`, `off`.

### Кнопка записи
Круг 88px, красный, иконка 22px, подпись и количество (`rec-count`, Share Tech Mono 13px). Hover светлее, `:active` сжатие до 0.97 за 160ms, disabled тёмно-красный и серо-розовый текст. Единственный красный элемент.

### Кнопки
Высота 38px (small 32px), радиус 6px, граница `line`, фон `surface-raised`, вес 600; hover `#303237`; `:active` сдвиг на 1px вниз; disabled прозрачность 0.5.
- **Primary:** алюминиевая клавиша, hover плоский `aluminium-top`.
- **Quiet:** без фона и границы, текст `text-dim`, hover подложка `surface-raised`.

### Переключатель направления
Радиогруппа в чёрном лотке (3px отступ, радиус 8px). Выбранный пункт: `surface-raised` с тонкой рамкой; фокус виден через `:has(input:focus-visible)`; в disabled прозрачность 0.6.

### Индикаторы (meters)
Четыре кнопки-фильтра: «Добавится», «Уже есть», «Проверить», «Не найдено». Подпись слева, малый счётчик справа. Выбранный (`aria-pressed`): янтарная рамка и тёплый фон `#29251d`. Hover усиливает границу до `#4a4d53`.

### Рабочая область и баннеры
Панель `surface` с границей. Баннер: иконка 20px и текст, снизу линия; тон `error` (кирпичный) и `ok` (янтарная иконка). Пустое состояние: заголовок 22px и абзац `text-dim`, макс. ширина 560px. Прогресс: дорожка 6px в чёрном, янтарная заливка растёт через `transform` за 300ms.

### Подключение сервиса
Две колонки с разделителем. Шаги пронумерованы круглыми значками (28px, чёрные, янтарная моноширинная цифра). Код устройства показывается в большом счётчике. Ожидание: малая катушка 20px вращается рядом с текстом.

### Поля ввода
Высота 38px, фон `window-black`, граница `line`, радиус 6px, моноширинный текст; placeholder `#7d828a`. Поиск: иконка слева, шрифт Golos Text. Фокус: общее янтарное кольцо 2px с отступом 2px. Ошибка поля: текст `brick` 13px под полем.

### Таблица треков
Панель фильтров (вкладки `filter-tab` с моноширинным числом; число янтарное или кирпичное по тону) и поиск. Липкая шапка 13px `text-dim`, строки с отступом 10px 18px, разделители `#292b2f`. Ячейка трека: точка сервиса, название 600, исполнители `text-dim`. Статусы (`data-status`): добавится янтарь, уже есть `text-dim`, проверить `#f6d38e`, не найдено кирпич; всегда иконка 16px и слово, не только цвет.

### Разбор спорных
Две колонки (1fr / 1.4fr): слева исходный трек, справа список кандидатов. Кандидат: радио, название, метаданные справа; выбранный: янтарная рамка и фон `#2c2820`; `accent-color` янтарный.

### История
Строки сеткой `200px / 1fr / auto`: дата (моноширинная), описание, действие. Разделитель `#292b2f`.

### Навигация
Вкладки верхней панели: без фона, `text-dim`; выбранная (`aria-selected`) на `surface-raised` с текстом `text`.

### Движение
Лёгкая кривая `--ease-out: cubic-bezier(0.16, 1, 0.3, 1)` для катушек, цифр, прогресса и кнопки записи; базовые длительности 140-160ms для hover, 300-600ms для данных. При `prefers-reduced-motion: reduce`: вращение катушек отключено, прокат цифр и рост прогресса без перехода.

## Do's and Don'ts

### Do:
- **Do** использовать токены из `:root` в `src/web/styles.css`; новых цветов без роли не заводите.
- **Do** оформлять любую новую цифру, которая что-то считает, как окошко-счётчик (чёрное, янтарное, вдавленное).
- **Do** помечать статусы иконкой и словом вместе с цветом.
- **Do** добавлять каждую строку сразу в оба словаря, `en.ts` и `ru.ts`; по-русски на «вы».
- **Do** крутить катушки только пока идёт работа и уважать `prefers-reduced-motion`.
- **Do** оставлять видимым янтарный фокус-контур 2px на всех интерактивных элементах.

### Don't:
- **Don't** красить в красный ничего, кроме кнопки записи.
- **Don't** использовать янтарь для заливок, заголовков и обычных кнопок.
- **Don't** делать главное действие красным или янтарным: это алюминиевая клавиша.
- **Don't** ставить цвета Яндекса и Spotify на что-либо крупнее точки 10px.
- **Don't** возвращаться к категорийному степперу и одинаковым карточкам сервисов.
- **Don't** писать строки интерфейса прямо в компонентах или в ответах сервера в обход словарей.
